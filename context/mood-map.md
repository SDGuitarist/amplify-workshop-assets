# Mood Map: Content Calendar → Visual Variants

Every post mapped to its mood class and intensity. Use this when generating graphics.

**Mood reference:** Open `mood-preview.html` to see all variants visually.

**Usage:** Apply the mood class to the card/story container element.
- Subtle: `<div class="card mood-framework">`
- Bold: `<div class="card mood-urgency mood-bold">`
- Launch default: `<div class="card">` (no mood class needed)
