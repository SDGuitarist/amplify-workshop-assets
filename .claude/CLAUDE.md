# Amplify Workshop — Content Pipeline

## What This Is

A content generation workspace for promoting the Amplify workshop (April 25, 2026). Commands generate social media posts that sound like Alex, follow the content calendar, and never break voice rules.

## Context Files (Read Only When Needed)

| File | When to Read | Purpose |
|------|-------------|---------|
| `context/brand-voice.md` | Every time you generate a post | Voice DNA, samples, banned words, platform adjustments, drafting principles |
| `context/content-calendar.md` | When you need to look up what's scheduled for a date | Posting schedule, hooks, timing, urgency triggers, framework bank |
| `context/workshop-arc-v2.md` | When a post references a specific workshop phase or framework | Full workshop curriculum, quotes, exercises, thesis |
| `context/voice-reference-extracts.md` | When drafting persuasive or cinematic copy | Tone patterns, persuasion structure, gold examples. Read-only reference. Does NOT override brand-voice.md or content-calendar.md. |

Do NOT load all four files at once. Load brand-voice.md for every post. Load voice-reference-extracts.md when the post needs cinematic or persuasive depth. Load the others only if the post requires calendar context or workshop content.

## Rules

1. Follow every rule in `context/brand-voice.md`. No exceptions.
2. No em-dashes. Ever. Use periods, commas, or line breaks.
3. No banned AI vocabulary (full list in brand-voice.md).
4. Maximum one exclamation mark per post. Zero is better.
5. One CTA per post. Never stack multiple asks.
6. Never fabricate stats, testimonials, or seat counts.
7. If a post references a framework from the workshop arc, read the relevant section in `context/workshop-arc-v2.md` first. Don't paraphrase from memory.
8. Every post must pass the voice check: Does this sound like Alex talking to a peer in a room? If it sounds like a marketing department, rewrite it.
